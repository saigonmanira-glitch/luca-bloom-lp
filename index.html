Problem

ハサミ式の拡張器具で、
こんな経験はありませんか。

  • アームから皮膚がずるっと滑る丸い棒状のアームは表面に引っかかりがなく、広げた位置で止まりません。
  • 「あと少し」が調整できないラチェット式は歯1枚ぶんずつしか動かず、ちょうどいい幅の手前か先で止まります。
  • ロックが外れて急に閉じる噛み合いが外れると、内蔵バネの力で2本のアームが一気に閉じます。
  • 1点だけが痛い断面が円形のアームは皮膚に線で当たるため、圧力が1か所に集中します。

Mechanism

4つの構造で、
その悩みを機械的に解決します。

STRUCTURE 1 / 送りネジ

回した分だけ、正確に広がる。

本体の中に送りネジを内蔵。操作部を回すとネジシャフトが回転し、ネジにかみ合った可動アームがまっすぐ移動します。ネジは台形ネジTr8×2の1条ネジで、1回転で進む距離（リード）は2.0mmです。

0.5mm¼回転あたり

STRUCTURE 2 / セルフロック

手を離しても、閉じない。

皮膚が縮もうとしてアームを押し戻しても、ネジは逆回転しません。これをセルフロックと呼びます。ネジ山の傾き（進み角）が、摩擦で止まる限界の角度（摩擦角）より小さいと成立します。バネを使っていないため、ロックが外れて急に閉じる仕組みそのものがありません。

STRUCTURE 3 / 3段アーム

入れやすく、滑らず、挟まない。

アームは長さ40mm。先端から根元へ3つの形を連続させています。細い先端で入れ、ふくらみで広げ、根元のくぼみで皮膚の位置を決めます。皮膚は縮もうとする力で自然にくぼみへ収まり、先端側へ抜けることも、本体側へ滑り込んで挟まれることも防ぎます。

STRUCTURE 4 / 面で支える断面

1点に集中させず、面で広げる。

アームの断面は幅6mm。皮膚に当たる面を平らにし、角をR（丸み）で落としています。丸棒のように線で当たらず、面で当たるので、広げる力が分散します。

+ 平行移動

最後まで平行に、最大70mm。

可動アームは本体の溝（スリット）に沿って、姿勢を変えずに直線移動します。支点を中心に開くハサミ式と違い、2本のアームは常に平行。ネジの長さをそのまま移動距離に使うため、移動距離（ストローク）は60mm、最大間隔は70mmあります。

How to use

使い方

  1. 洗って乾かす使用前後に中性洗剤で洗い、水気を拭き取ります。
  2. 最小幅まで閉じる本体側面の「CLOSE」矢印の方向へ操作部を回し、アーム間隔を最小の10mmにします。
  3. 先端から入れる2本のアームを先端（収束部）から包皮の口に入れ、根元のくぼみ部に皮膚が収まる位置まで進めます。
  4. 少しずつ回すCLOSEと逆方向へ回します。¼回転で0.5mm広がります。痛みを感じる手前で止めてください。
  5. その幅で保持する手を離してもセルフロックで幅が保たれます。
  6. 閉じてから外すCLOSE方向へ回してアームを閉じ、ゆっくり抜きます。
ご使用上の注意
  • 本品は医療機器ではありません。病気の治療や診断を目的とするものではありません。
  • 痛み・出血・腫れ・傷がある場合は使用を中止し、医師にご相談ください。
  • 皮膚が元の位置に戻らなくなった場合は、すぐに医療機関を受診してください。
  • 一度に大きく広げず、痛みのない範囲で少しずつ調整してください。

Glossary

用語の説明

送りネジlead screw
ネジを回す動きを、まっすぐ進む動きに変える仕組み。工作機械や車のジャッキにも使われます。
台形ネジTr
ネジ山の断面が台形のネジ。一般的な三角のネジより山が太く、力を伝える用途に向きます。「Tr8×2」は外径8mm・ピッチ2mmの意味です。
1条ネジ
ネジ山が1本のらせんで刻まれたネジ。2本のらせんなら2条。条数が少ないほど1回転の移動量は小さく、戻りにくくなります。
ピッチ／リード
ピッチは隣り合うネジ山の間隔、リードは1回転で進む距離。1条ネジではどちらも同じ2.0mmです。
セルフロック
押し戻す力が加わってもネジが勝手に回らない性質。ネジの傾き（進み角5.2°）が摩擦の限界角度（摩擦角11.7°）より小さいため成立します。
ラチェット
歯車と爪を噛み合わせて、1方向にだけ段階的に動かす仕組み。噛み合いが外れると保持力がなくなります。
POMpolyacetal
ポリアセタール樹脂。摩擦が小さく摩耗に強いため、歯車やファスナーなど動く部品に使われるプラスチックです。
R（アール）
角を丸く落とした形状。「R2」は半径2mmの丸みを意味します。

FAQ

よくある質問

1回転でどれくらい広がりますか？

2.0mmです。¼回転（90°）なら0.5mm。最小10mmから最大70mmまで、30回転で移動します。

手を離すと閉じてしまいませんか？

閉じません。ネジの進み角5.2°が摩擦角11.7°より小さいため、皮膚から押し戻す力がかかってもネジは回りません（セルフロック）。閉じるときは操作部をCLOSE方向へ回します。

どの方向に回すと閉じますか？

本体側面に刻印された「CLOSE」の矢印方向です。深さ0.3mmの刻印なので、指でも確認できます。

素材は何ですか？

全部品POM（ポリアセタール樹脂）です。金属やバネは使用していません。

医療機器ですか？

医療機器ではありません。ご自身の判断で使うセルフケア器具です。症状がある場合は医師にご相談ください。
