# SNS ブランド素材

| ファイル | 用途 | サイズ |
|---|---|---|
| `icon.png` / `icon.svg` | プロフィールアイコン（紺背景。X・Instagram・Threads・note 共通） | 1000×1000 |
| `icon-white.png` / `icon-white.svg` | プロフィールアイコン（白背景版） | 1000×1000 |
| `x-header.png` | X のヘッダー画像 | 1500×500 |
| `note-header.png` | note のヘッダー画像 | 1920×1006 |

- アイコン：紺（#161A29）の地に金（#E3B34E）の6枚の花弁。中央を空けて「開く＝Bloom」を表現。円形に切り抜かれても欠けないよう、図柄は直径の70%以内に収めています。32px まで縮めても形が判別できます。
- ヘッダー画像は白背景です。
- X のヘッダーは、左下（横 0〜380px・縦 330〜500px）がアイコンで隠れるため、文字をその範囲の外に置いています。
- note のヘッダーは画面幅によって上下が切り取られるため、文字と製品を縦 304〜702px の帯に収めています。
- 製品の画像は LP と同じ 3D モデル（`src/scene/`）から書き出したものです。
