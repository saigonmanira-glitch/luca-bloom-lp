# 海外（英国・オーストラリア）向け SNS 自動投稿キット

英語の Instagram・X・Threads を自動投稿するための素材一式です。日本語版の画像 `sns/ig/001〜030.jpg` と同じ番号・同じテーマで、英語の投稿を30本用意しています。

## ファイル

| ファイル | 内容 |
|---|---|
| `posts.json` | 投稿30本。各投稿に、画像の文字（`image`）、Instagram・X・Threads の本文、画像の説明文（`alt`：画面読み上げ用の代替テキスト）、日本語訳（`ja`）が入っている |
| `prompts/system.md` | 文章を書くAIに渡す**システムプロンプト**（AIの役割・使ってよい製品情報・規制上のルール・文体を決める指示文）。日本語訳つき |
| `prompts/caption.md` | 投稿1本ごとにAIへ送る**依頼文の型**。出力はJSON（決まった形のデータ）で受け取る。日本語訳つき |
| `prompts/image.md` | 英語版の画像 `sns/en/ig/001〜030.jpg` を作るときの指示書（日本語画像と同じレイアウトで文字だけ英語にする）。日本語訳つき |
| `../../tools/sns-check.mjs` | 投稿前の**自動チェック**（禁止語・文字数・ハッシュタグ・日本語訳の有無）。`npm run check` でも毎回実行される |

## 自動投稿の流れ（推奨）

1. **今ある30本を使う場合**：`posts.json` を番号順に1日1本投稿する（30日分）。
2. **新しい投稿をAIに書かせる場合**：`prompts/system.md` をシステムプロンプトに、`prompts/caption.md` を依頼文にして生成する。
3. **投稿前に必ずチェック**：`node tools/sns-check.mjs 出力したファイル.json` を実行し、「OK」のときだけ投稿する（自動投稿の仕組みに組み込むと、規制に触れる文章が誤って投稿されるのを止められます）。
4. 画像は `https://luca-bloom.com/sns/en/ig/001.jpg` のように公開URLで渡す（Instagram の投稿API は公開URLの画像しか受け付けないため）。英語版の画像 `sns/en/ig/001〜030.jpg` は、同じ番号の日本語画像と同じ構図で作成済みです。

**自動投稿は luca-bloom-sns リポジトリの `global-post.yml` で動きます**（毎日16:52、英語用の合鍵を登録した媒体だけに投稿）。Claudeが新しく書いた投稿の画像は `sns/en/auto/` に置かれます。

## 投稿の時間（1つの英語アカウントで両国に届ける）

| 日本時間 | 英国 | オーストラリア（シドニー） |
|---|---|---|
| **毎日 17:00** | 9:00（夏時間）／8:00（冬時間） | 19:00（夏時間）／18:00（冬時間） |

英国の朝の通勤時間と、オーストラリアの夕方の時間帯に同時に届きます。

プロフィール画像・ヘッダー（X・Facebook・YouTube）・北米の投票呼びかけ画像は `sns/en/brand/`（`README.md`）にあります。

## プロフィール文（英語・日本語訳）

広報は英語1本で行うため、全市場共通です。販売国が増えても書き換えずに使えるよう、国名は入れていません。各国の規制に合わせ、病名・効果・比較・価格・「限定」を入れていません。

**X（155文字／上限160文字）**　名前欄：`Luca Bloom | Foreskin care tool`

```
Foreskin care tool from Tokyo. Opens up to 70 mm, stepless, stays where you stop. Discreet box. Not a medical device. 18+. Available on Amazon: link below.
```

日本語訳：東京発の包皮ケアツール。最大70mmまで無段階に開き、止めた位置で保たれます。中身がわからない箱でお届け。医療機器ではありません。18歳以上。Amazonで販売中：下のリンクから。

**Instagram・Threads（140文字／上限150文字）**　名前欄：`Luca Bloom | Foreskin care`（26文字／上限30文字）

```
Foreskin care tool
▷ Opens up to 70 mm, stepless
▷ Stays put when you let go
▷ Discreet box
Not a medical device · 18+
Available on Amazon ↓
```

日本語訳：包皮ケアツール／▷ 最大70mmまで無段階に開く／▷ 手を離しても止まる／▷ 中身がわからない箱／医療機器ではありません・18歳以上／Amazonで販売中↓

プロフィールのリンク：`https://luca-bloom.com/en/`（英語LP。画面上部の「Language」から各国のページへ移れます）

## 投稿のテーマ配分（30本）

| テーマ | 本数 | 番号 |
|---|---|---|
| 製品の機能・設計 | 8 | 001, 003, 009, 015, 017, 022, 025, 030 |
| 共感・ブランドの考え方 | 8 | 002, 004, 010, 012, 018, 020, 026, 028 |
| 日常の場面（更衣室・旅行など） | 3 | 008, 016, 024 |
| 清潔のコツ（一般的な衛生情報） | 4 | 005, 013, 021, 029 |
| 安全（使用上限・使わない場合） | 2 | 011, 027 |
| 素材・品質・箱 | 3 | 006, 014, 019 |
| 販売先 | 2 | 007, 023 |

日本語版にあった「初期ロット100個限定」「Amazonで5,800円」（価格・限定の表現）は、英語版では「販売先の案内」「東京の小さなチーム」に置き換えています。

## 規制上のルール（要点）

詳しくは `prompts/system.md`。自動チェックの禁止語は `tools/claims.mjs`（多言語LPのテストと共用）。

- 治療・改善・予防などの効果をうたわない。病名（phimosis など）を書かない
- 比較・最上級（best・widest など）、価格、「限定」、体験談を入れない
- 性的な内容にしない。不安をあおらない
- 使い方に触れるときは使用上限（1回30分・24時間で1時間）を添える
- 清潔のコツは一般的な内容に限り、「医学的な助言ではありません」と添える

どの表現でも法的に問題がないと保証できるものではありません。英国・豪州での配信を始める前に、現地の規制に詳しい専門家への確認をおすすめします。
